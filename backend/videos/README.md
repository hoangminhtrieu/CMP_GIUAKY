# Videos Demo Chức Năng Đồ Án TOEIC

Thư mục này chứa các video quay màn hình (full screen) demo từng chức năng theo yêu cầu đồ án:

1. `01_demo_upload_word_file.mp4` - Demo Giảng viên upload file Word (.docx), kiểm tra bắt lỗi định dạng nếu thiếu thẻ/sai số câu và import thành công khi file chuẩn 100%.
2. `02_demo_admin_preview_and_edit.mp4` - Demo Giảng viên xem trước đề thi (rà soát chính tả, ảnh minh họa) và chỉnh sửa câu hỏi/đáp án.
3. `03_demo_student_exam_taking.mp4` - Demo Học viên chọn đề, làm bài thi: đồng hồ đếm ngược 75 phút, cảnh báo sắp hết giờ (<5 phút), chọn/đổi/hủy đáp án, lưới câu hỏi tổng quan và tự động thu bài khi hết giờ.
4. `04_demo_submit_and_scoring.mp4` - Demo Cảnh báo câu chưa làm khi nộp bài và màn hình hiển thị kết quả (tổng đúng, sai, bỏ qua, điểm số).
